================================================================================
    親子資訊 LINE Bot — 全方位親子旅遊比價與景點探索平台 企劃書
================================================================================

專案名稱: 親子資訊 LINE Bot (ParentChild Travel Bot)
版    本: v2.0 — 基於現有 StayPulse 平台之全面升級計畫
日    期: 2026-08-12
目    標: 打造一站式親子旅遊智能助手，整合飯店比價、親子景點、表演劇場搜尋，
          並透過 LINE Bot 提供即時查詢服務

================================================================================
一、專案總覽
================================================================================

【現有基礎 (StayPulse)】

目前已有一套運作中的飯店搜尋比價平台，部署於：
https://parentchild.onrender.com/

技術棧如下：

  項目          現有技術
  ──────────    ─────────────────────────────────────────
  前端          React 18 + Vite 6 + Lucide Icons
  後端          Express.js (Node.js)
  資料庫        SQLite (better-sqlite3) — 飯店、景點、表演、城市資料
  外部 API      SerpAPI (Google Hotels)、文化部 Open Data API
  訂房平台連結  Agoda、Booking.com、Trip.com Deep Link
  LINE Bot      基礎文字指令查詢 + Flex Message 卡片回覆
  部署          Docker + Render.com

【升級目標】

將現有平台從「飯店比價工具」升級為完整的親子旅遊一站式平台，新增以下核心能力。

【LINE Bot 回覆格式設計】

  飯店查詢 → Flex Message 卡片輪播
    - 飯店圖片 + 名稱 + 評分 + 最低價
    - 按鈕 1: 「🏷 前往最低價 Agoda」→ Deep Link
    - 按鈕 2: 「📊 查看完整比價」→ 網站比價頁面
    - 按鈕 3: 「❤️ 加入收藏」→ PostBack

  景點查詢 → Flex Message 卡片
    - 景點圖片 + 名稱 + 地址
    - 按鈕 1: 「📍 Google Maps 導航」
    - 按鈕 2: 「📖 查看詳細介紹」→ 官方網站

  表演查詢 → Flex Message 卡片
    - 演出海報 + 劇名 + 場館 + 日期
    - 按鈕 1: 「🎫 前往購票」→ OPENTIX/Klook
    - 按鈕 2: 「📍 場館位置」→ Google Maps

【資料庫 Schema (SQLite)】

  hotels (飯店主表)
  ──────────────────────────────────────────────
  id              INTEGER  PRIMARY KEY
  hotel_key       TEXT     UNIQUE NOT NULL
  name_zh         TEXT     NOT NULL
  name_en         TEXT     NOT NULL
  city_name       TEXT     NOT NULL
  address         TEXT     NOT NULL
  description     TEXT
  rating          REAL     DEFAULT 4.8
  reviews_count   INTEGER  DEFAULT 1200
  hotel_class     INTEGER  DEFAULT 4
  base_price      INTEGER  DEFAULT 3200
  image_url       TEXT
  amenities       TEXT     (JSON array)
  keywords        TEXT

  family_attractions (親子景點)
  ──────────────────────────────────────────────
  id              INTEGER  PRIMARY KEY
  attraction_key  TEXT     UNIQUE NOT NULL
  name            TEXT     NOT NULL
  city_name       TEXT     NOT NULL
  address         TEXT     NOT NULL
  category        TEXT     DEFAULT '室內樂園'
  ticket_price    INTEGER  DEFAULT 350
  rating          REAL     DEFAULT 4.8
  reviews_count   INTEGER  DEFAULT 1500
  image_url       TEXT
  features        TEXT
  keywords        TEXT
  official_url    TEXT     (新增：官方網站)
  google_maps_url TEXT     (新增：Google Maps)

  family_shows_galleries (親子表演藝廊)
  ──────────────────────────────────────────────
  id              INTEGER  PRIMARY KEY
  show_key        TEXT     UNIQUE NOT NULL
  title           TEXT     NOT NULL
  venue           TEXT     NOT NULL
  city_name       TEXT     NOT NULL
  ticket_price    INTEGER  DEFAULT 600
  rating          REAL     DEFAULT 4.9
  reviews_count   INTEGER  DEFAULT 620
  image_url       TEXT
  event_date      TEXT
  highlights      TEXT
  keywords        TEXT
  ticket_url      TEXT     (新增：購票連結)
  venue_maps_url  TEXT     (新增：場館地圖)

  price_history (價格歷史) [新增]
  ──────────────────────────────────────────────
  id              INTEGER  PRIMARY KEY
  hotel_key       TEXT     FK → hotels
  provider_name   TEXT
  price           INTEGER
  check_in_date   TEXT
  check_out_date  TEXT

七、LINE Bot 完整指令參考
================================================================================

【飯店相關】

  📍 搜尋飯店 {地點}
     範例: 搜尋飯店 宜蘭
     回覆: 該地區飯店 Flex 卡片輪播

  💰 搜尋飯店 {地點} {預算}
     範例: 搜尋飯店 台北 5000
     回覆: 預算內飯店列表

  📊 比價 {飯店名稱}
     範例: 比價 蘭城晶英酒店
     回覆: Agoda / Booking / Trip.com 各平台價格

  🛒 訂房 {飯店名稱} {入住日}-{退房日} {大人}大{小孩}小
     範例: 訂房 蘭城晶英 0815-0817 2大2小
     回覆: 各平台訂房直連按鈕 (含日期人數預填)

【景點與表演】

  🎠 親子景點 {地點}
     範例: 親子景點 台北
     回覆: 景點 Flex 卡片 (含導航/介紹連結)

  🎭 親子表演 {地點}
     範例: 親子表演 宜蘭
     回覆: 表演 Flex 卡片 (含購票連結)

  🖼 展覽 {地點}
     範例: 展覽 台中
     回覆: 文化部官方展覽資訊

【行程與收藏】

  📋 我的行程
     回覆: 已儲存行程列表

  ❤️ 我的收藏
     回覆: 已收藏飯店列表

  🔔 設定提醒 {飯店名稱} {目標價格}
     範例: 設定提醒 蘭城晶英 5000
     回覆: 確認訊息，當價格低於 5000 時通知

【系統指令】

  ❓ 幫助 / help
     回覆: 完整指令說明

  🏠 首頁
     回覆: 網站連結按鈕
